# Digital Forensics Portfolio

A collection of digital forensics investigations completed using **Autopsy 4.3.0**, covering disk image analysis, deleted file recovery, keyword searching, and evidentiary reporting.

## Skills Demonstrated

- **Disk Image Examination** — Loading and analysing E01 (Expert Witness) and DD (raw) image formats
- **File System Metadata Analysis** — Interpreting MAC times (Modified, Accessed, Created) to establish timelines
- **Deleted File Recovery** — Recovering files from unallocated space and documenting cluster numbers
- **Keyword Searching** — Conducting targeted searches across allocated and unallocated space
- **Evidence Tagging** — Organising relevant artifacts for legal review
- **Forensic Reporting** — Generating Excel and HTML reports with tagged results and metadata analysis

## Tools Used

| Tool | Purpose |
|---|---|
| Autopsy 4.3.0 | Primary forensic examination platform |
| The Sleuth Kit | Underlying file system analysis library |
| FTK Imager | Disk image acquisition (simulation) |
